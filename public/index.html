CHAPTER 4: QUADRATIC EQUATIONS Page 6 / 20
💡 Simple Idea:

Equations of the form ax² + bx + c = 0 (a ≠ 0). Roots real hain ya imaginary, yeh akela Discriminant D decide karta hai.

📐 Must-Know Board Formula:
D = b² − 4ac

• If D > 0: Two distinct real roots | • If D = 0: Two equal roots | • If D < 0: No real roots

⚡ Topper Shortcut Trick:
If a + b + c = 0, one root is ALWAYS 1!
Aur doosra root seedha c / a hota hai. Example: 3x² - 5x + 2 = 0 mein 3 - 5 + 2 = 0 hai, to roots bina solve kiye seedha 1 aur 2/3 hain!
MARKS BACHAO ⚠️ Common Board Exam Trap:

Formula mein b² nikaalte waqt agar b = -7 hai, to student jaldi mein -49 likh dete hain. Yaad rakho: negative number ka square hamesha POSITIVE (+49) hota hai!
